# 🏔️ Antexon.pl — Strona O Nas

Oficjalna strona internetowa zespołu **Antexon** przedstawiająca skład, rolę poszczególnych członków oraz naszą misję w świecie Minecrafta.

---

## 🛠️ Technologie

 Projekt został stworzony w oparciu o czysty, lekki i responsywny kod:

* **HTML5** — struktura i treść strony
* **CSS3** — nowoczesny styl (Glassmorphism, CSS Grid, Flexbox)
* **Vercel** — hosting i automatyczny deployment (CI/CD)
* **GitHub** — kontrola wersji
